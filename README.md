# LevelPvP – Paper 26.2

Paper 26.2 / Java 25 / Gradle project with GitHub Actions build workflow.

Build locally with `gradle clean build`. The JAR is created in `build/libs/`.
After uploading the project to GitHub, open **Actions → Build LevelPvP** and download the `LevelPvP-JAR` artifact.

Commands:
- `/stats`
- `/delivery`
- `/extract <Anzahl>`
- `/levelcap global <Level>`
- `/levelcap player <Spieler> <Level>`
- `/levelpvp unban <Spieler>`

Admin permission: `levelpvp.admin` (default OP).

Back up your server and test on a separate test server before using it live.
